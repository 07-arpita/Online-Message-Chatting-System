# Online Message Chatting System

## Project Description
Online Message Chatting System is a real-time chat application where users can register, login and send messages to other users.

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript
- Socket.io Client

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.io

## Features
- User Registration
- User Login
- Real-time Messaging
- Messages stored in MongoDB
- User Authentication
- Logout Functionality
